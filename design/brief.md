# xnan.me design brief

## Positioning

XNAN is presented as an independent AI product builder. The site is a concise personal interface rather than a résumé or agency landing page. It avoids unsupported client logos, metrics, employment history, and project claims.

## Reference translation

- **Primary structure:** editorial portfolio hero with one large statement and a compact selected-work section.
- **Motion language:** a single “signal field” motif representing Think → Shape → Ship.
- **Components:** restrained project cards and process rows normalized into one type, color, spacing, and radius system.
- **Not borrowed:** MotionSites prompt text, source media, logos, or gated assets.

## Visual system

- Obsidian background and warm paper panels create clear pacing.
- Acid green is the only primary accent; purple and coral are minor signal colors.
- System fonts avoid network dependencies and layout shifts.
- Abstract visuals are CSS-generated, so the repository has no uncertain media licenses.

## Motion rules

- Motion reveals hierarchy, indicates system state, or provides pointer feedback.
- Continuous orbit and marquee animation stop under `prefers-reduced-motion`.
- Pointer tilt runs only on fine pointers and is decorative.
- Content remains complete without JavaScript.

## Acceptance criteria

- No horizontal document overflow at 320 px.
- Navigation, project, GitHub, and skip links work.
- One semantic H1, ordered section headings, and visible keyboard focus.
- No third-party JavaScript, fonts, images, or autoplay media.
- Desktop and mobile views have no overlaps, clipped primary copy, or empty sections.
